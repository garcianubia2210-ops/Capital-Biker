# 🏍️ Capital Biker

## Tienda especializada en accesorios para motociclistas

Capital Biker es un proyecto de desarrollo web realizado como parte del programa de formación de Análisis y Desarrollo de Software del SENA.

El proyecto consiste en una tienda virtual especializada en productos y accesorios para motociclistas, permitiendo a los usuarios consultar productos, visualizar sus características, agregarlos al carrito y realizar un proceso de compra.

## 🚀 Tecnologías utilizadas

- Python
- Django
- HTML5
- CSS3
- JavaScript
- MariaDB
- XAMPP
- Git y GitHub

## 🛒 Funcionalidades

- Registro e inicio de sesión de usuarios.
- Catálogo de productos.
- Organización de productos por categorías.
- Visualización del detalle de cada producto.
- Selección de variantes de productos.
- Carrito de compras.
- Aumento y disminución de cantidades.
- Eliminación de productos del carrito.
- Proceso de checkout.
- Registro de pedidos.
- Panel administrativo de Django.
- Diseño frontend adaptado a la identidad visual de Capital Biker.

## 🎨 Identidad visual

El proyecto utiliza principalmente una combinación de:

- 🟠 Naranja: `#ff6600`
- ⚫ Negro y tonos oscuros.
- ⚪ Blanco.

La interfaz busca ofrecer una experiencia moderna, clara y orientada a los usuarios del mundo motociclista.

## 📁 Estructura general

El proyecto está organizado en diferentes aplicaciones y directorios:

- `catalogo/` – Gestión del catálogo y carrito.
- `home/` – Página principal.
- `usuarios/` – Gestión de usuarios.
- `config/` – Configuración principal de Django.
- `static/` – Archivos CSS, JavaScript e imágenes.
- `templates/` – Plantillas generales del proyecto.
- `media/` – Archivos multimedia locales.
